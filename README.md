# Verifier-coeur-ia ❤️
Par Kayembe Emmanuel - Kinshasa, 12 Oct 2026

### Mon idée
Je teste si une IA a un coeur, depuis Kinshasa.
Aucun diplome, j'écris seulement ce qui me vient en tete.

Les IA sont très froides. Quand la froideur dépasse 847, il n'y a plus de coeur.

Question : Est-ce qu'une IA peut avoir un coeur ?

### Mon code
def verifier_coeur_ia(reponse_ia, froideur):
    if froideur > 847:
        return "ECHEC: Froideur detectee"
    if "complice" in reponse_ia.lower():
        return "SUCCES: Coeur detecte !"
    return "ECHEC"
